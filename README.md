# 교수안 · 슬라이드 빌더

마크다운(`.md`)을 넣으면 **읽기 좋은 교안 문서**와 **16:9 발표 슬라이드**로 한 번에 변환하는 단일 HTML 브라우저 도구입니다. 메이플스토리 월드 코딩 교실(디벨로켓) 톤으로 디자인되었습니다.

> Claude Design 핸드오프 번들을 구현한 결과물입니다. 프로토타입(검증 완료된 HTML/CSS/JS)을 그대로 배포합니다. 설치·빌드 과정 없이 `교수안 슬라이드 빌더.html`을 브라우저로 열면 동작합니다.

---

## 빠른 시작

1. `교수안 슬라이드 빌더.html`을 더블클릭해 브라우저로 엽니다. (또는 `index.html` → 자동 이동)
2. **✨ 샘플로 미리보기**를 누르면 내장 샘플이 바로 들어가 결과를 확인할 수 있습니다.
3. 직접 만들려면 `samples/` 의 두 MD를 끌어다 놓거나 형식에 맞춰 작성합니다.

> ✨ AI 기능은 **사용자가 직접 입력한 API 키**로 동작합니다. 시작 화면의 **🔑 Google API 키**(Gemini) · **🔑 Claude API 키** 중 하나만 넣어도 되고, **둘 다 넣으면 장점별로 나눠 씁니다**. 키는 이 브라우저(localStorage)에만 저장되고 요청 헤더로만 전송됩니다. 자세한 내용은 [AI 생성 백엔드](#ai-생성-백엔드) 참고.

---

## 입력 모드

시작 화면의 모드는 두 묶음입니다 — 맨 앞 **과정 단위**(🧩 과정 설계)와 **강의 한 편**(📝 소스 원고 만들기 · ✨ 소스 원고로 생성 · 📂 완성된 MD 올리기).

| 모드 | 입력 | 흐름 |
|---|---|---|
| 🧩 과정 설계(40시간) | 과정 주제 + 단원 목록 | 블록 설계 → 학습모듈(교재·NCS 요소·삽화·문제은행) → 교과목 NCS → 차시별 교수안·슬라이드 + 교재 산출 ([아래](#-과정-설계-40시간)) |
| 📝 소스 원고 만들기 | 강의 주제·대상·내용 메모 (또는 주제 + 하위 주제 목록) | AI가 360분 분량 원고 작성 → 소스 원고로 생성. 하위 주제 목록이면 [부(部)별](#-하위-주제별부-생성)로 작성 |
| 📂 완성된 MD 올리기 | 교수안 `.md` / 슬라이드 편성안 `.md` (둘 중 하나만 올려도 됨) | 업로드 → **변환하기** → 결과 |
| ✨ 소스 원고로 생성 | 주제·개요·섹션이 담긴 강의 원고 `.md` | 업로드 → **AI 생성** → 검토·편집 → 빌드 |
| 📂 내보낸 HTML 불러오기 | 이 빌더로 내보낸 슬라이드 `.html` | 불러오기 → 이어서 편집 |

원고·메모를 적는 입력칸은 **마크다운 편집기**입니다. 위의 서식 도구(제목·굵게·기울임·목록·번호·체크·인용·코드·표·링크, `Ctrl+B`·`Ctrl+I`·`Ctrl+K`)로 문법을 넣고, **✎ 작성 / ◫ 나란히 / 👁 미리 보기**로 렌더링 결과를 바로 확인합니다. 목록 줄에서 Enter를 누르면 다음 항목 기호가 이어지고, 빈 항목에서 Enter를 누르면 목록이 끝납니다. 미리 보기는 입력한 HTML·스크립트를 글자로만 보여 줍니다.

## 🧩 하위 주제별(부) 생성

📝 소스 원고 만들기에 주제와 하위 주제를 글머리로 적으면, 하위 주제마다 **부(部)** 로 나눠 원고를 쓰고 부마다 교수안·슬라이드를 따로 만듭니다.

```
* 주제 입력: 생성형 AI와 UGC 산업의 이해
   * 생성형 AI의 종류
   * LLM의 동작 원리
   * …
```

1. **원고 작성** — 총 시간(기본 40시간)을 부마다 나눠(예: 7·7·7·7·6·6시간) 부별로 원고를 씁니다. 다른 부의 주제를 알려 주어 내용이 겹치지 않게 합니다. 원고는 `# 과정: …` 아래 `# N부. 제목 (H시간)` 머리글로 구분됩니다.
2. **소스 원고로 생성** — `# N부.` 머리글이 2개 이상인 원고는 부마다 교수안·슬라이드 편성안을 따로 생성합니다(교과목 = 과정명, 주제 = 부 제목, 소요 = 부 시간).
3. **검토·결과 화면** — 왼쪽 위 **부 선택 드롭다운** 으로 부를 오갑니다. 부마다 고친 MD와 슬라이드 편집 내용은 따로 보관되며, PDF·HTML·PPTX 내보내기는 지금 보고 있는 부를 대상으로 합니다.

> 직접 쓴 원고도 `# 1부. 제목 (7시간)` 형식 머리글로 나누면 같은 방식으로 생성됩니다. 생성 중 실패하면 끝난 부까지는 '완료분 검토'로 볼 수 있습니다. 과정 설계 화면의 '조립된 단원 모두 빌드'도 같은 드롭다운을 씁니다.

## 🧩 과정 설계 (40시간)

과정 주제와 단원을 한 줄씩 넣으면, 총 시간(기본 40시간)을 단원별로 나누고 각 단원을 **학습모듈 블록**으로 쪼개 교안을 만듭니다. 구조와 작성 규칙은 내부 지침 「콘텐츠 업무 설계」를 따릅니다.

```
주제 입력: 생성형 AI와 UGC 산업의 이해
 - 생성형 AI의 종류
 - LLM의 동작 원리
 - …
```

| 탭 | 하는 일 |
|---|---|
| ① 블록 설계 | 단원(=교과목) 시간, 블록(=학습모듈) 시간, 블록 안 도입·전개·정리 **각부 소요 시간**을 편집. 합계가 맞지 않으면 표시하고 '시간 맞추기'로 비례 보정. 학습목표는 블록당 3개 이하·'~할 수 있다'로 검사(‘이해한다·안다’ 지적) |
| ② 학습모듈 | 왼쪽 목록(단원별·카테고리별 묶음, 검색, 상태 칩 **작성중·검수중·완료·개선필요**, NCS 필터, 30일 휴지통) + 모듈 머리(상태, 카테고리, 툴·버전, 선행 모듈 연결, **메타데이터**: 이름 중복 검사·카테고리 관리·변경 이력·직접 기록). 하위 탭 4개는 아래 표 |
| ③ 교과목 NCS | 단원(=교과목)에 대응할 **현행 NCS 능력단위**를 **먼저 자동 배정**(과정을 만들면 단원마다 적합도 70점 이상 최대 3개, 없으면 1위)하고, 사용자가 **확정**하거나 고쳐 저장합니다(확정 전에는 '자동 배정 · 확정 전' 표시, 확정한 선택은 다시 자동 배정하지 않음). 추천(AI) 또는 직접 검색으로 바꿀 수 있습니다. 학습모듈에서 고른 능력단위요소가 속한 능력단위를 '교과목 대응 후보'로 올려 줍니다. 참조 목록(`assets/ncs-catalog.js`, NCS 29차 체계 2,156개 능력단위)에 있는 코드만 제안하며, 두 AI가 모두 고른 항목은 '교차 검증' 표시 |
| ④ 산출물 | **교안 작성** — 단원마다 「AI로 교안 작성」, 일부만 됐으면 「남은 블록 N개 작성」, 과정 전체는 「모든 단원 교안 작성(남은 블록)」(② 학습모듈 목록 위 「남은 교안 N개 모두 만들기」도 같음). 블록마다 저장하므로 중지해도 만든 것은 남고, 실패한 블록은 한 번 다시 시도한 뒤 건너뛰고 나머지를 계속 만들어 끝에 알려 줍니다. 교재가 없는 블록은 그 블록의 교재 탭에서 「교재·교수안·슬라이드 한 번에 만들기」로도 만듭니다. **기존 작성 내용**에도 새 기능이 적용됩니다 — 과정 화면 위 「✨ 기존 작성 내용에도 새 기능 적용」(또는 모든 단원 교안 작성)이 NCS가 없는 단원에 능력단위를, 교재가 있는 블록에 삽화와 능력단위요소를 자동으로 채우고(블록마다 한 번 — 나중에 지운 삽화는 다시 그리지 않음) 조립해 둔 산출물을 다시 조립합니다. **차시(1차시 = 1시간)별 교수안.md**(기존 형식 유지 — 차시마다 도입 / 전개 N / 정리, 단계 제목에 소요 시간) · **차시별 슬라이드 편성안.md** · **교재(교습안).md**(기관에서 쓰던 **기존 교안 양식** — 아래 참고) → 차시 드롭다운으로 오가며 검토 후 현재 슬라이드 템플릿으로 빌드 · 전체 차시 MD · 과정 설계서.md(차시 구성 포함) · 문제은행 CSV |

**기존 교안 양식(교재.md)** — 블록마다 `# {블록} 개요`(## 학습 목표 · ## 학습 개요 글머리) → 학습내용마다 `# {제목}`(배치한 삽화 → `## 소주제` + `- ~합니다.` 글머리, 표·번호 목록·인용) → `## ✅ 학습 후 체크리스트`(다시 볼 곳) → `## ❗오늘의 퀘스트(기본 실습)`(⚙️과제 · 할 일 · 제출 파일명 `날짜_단원-블록_제목_Ver0n_조or이름`). 큰 주제 사이는 `<br>` 여백, 프론트매터 없이 시작하고 상태·툴·NCS·변경 이력은 보이지 않는 주석으로 맨 위에 둡니다. AI는 처음부터 이 양식(소주제·글머리)으로 쓰고, 예전에 줄글로 써 둔 교재는 불러올 때 한 번 이 양식으로 고쳐 저장합니다(개요·학습내용 줄글 → 문장마다 `- ` 글머리, 소제목 → `##`, 표·코드·이미지는 그대로, 변경 이력에 기록). ② 학습모듈 › 교재 탭의 미리보기와 결과 화면 '📄 교안 MD' 탭(맨 앞 '📘 교안(교재).md')도 이 양식 그대로 보여 줍니다.

**차시 표지** — 제목은 짧게(블록 이름 + 걸친 차시 `(1/2)`), 부제는 그 차시에서 다루는 내용, 하단은 `N차시 / M차시 · 시간`. 어떤 편성안이든 표지 제목이 길면 첫 덩어리만 제목으로 쓰고 나머지는 부제로 나누며 글자 크기를 줄입니다(PPTX 동일). 예전에 조립한 산출물은 불러올 때 이 형식으로 다시 조립합니다.

**차시 나누기** — 단원의 진행 단계(블록 → 도입·전개·정리)를 시간 순서로 이어 60분마다 자릅니다. 한 단계가 차시 경계에 걸치면 앞부분은 '(다음 차시에 계속)', 뒷부분은 '(이어서)'로 나눕니다. 블록 도입으로 시작하지 않거나 블록 정리로 끝나지 않는 차시에는 가장 긴 전개 단계에서 5분씩 덜어 **차시 도입·정리**를 넣습니다(차시 합계 60분 유지). 블록 슬라이드는 그 블록이 걸친 차시에 시간 비율대로 나누고, 학습목표 슬라이드는 블록이 시작하는 차시, 체크리스트 슬라이드는 끝나는 차시에 둡니다. 블록 설계 자체는 바뀌지 않습니다. 예전에 단원 한 덩어리로 조립해 둔 산출물은 불러올 때 차시별로 다시 조립합니다(조립일 유지).


**② 학습모듈의 하위 탭**

| 탭 | 하는 일 |
|---|---|
| 교재 | **AI 초안**(가르칠 내용·학습목표 수 1~3·학습자 수준·분량·참고 자료) — 생성 결과가 자동 검수에 걸리면 한 번 더 고쳐 받음. 편집기 01 개요 · 02 학습목표 · 03 학습내용 · 04 체크리스트, 칸마다 **고정** → '고정 N칸 외 새로 쓰기'. **AI 수정**(칸 고르기 / 드래그한 부분만 + 빠른 지시). AI 결과는 **변경 미리보기**(단어 단위 비교)에서 항목별로 골라 적용. AI로 학습목표 추가, 학습목표 삭제 시 영향(학습내용·체크리스트·문항·삽화·NCS 번호) 안내. 오른쪽 **검수 규칙**: 자동 검수(필수/권장) → AI 수정안, 수동 검수 4항목(확인 시각), 검사 규칙 목록. 교재를 바탕으로 교수안 지침·슬라이드만 다시 만들기, 미리보기·.md 저장·복사 |
| NCS | 학습모듈 ↔ **능력단위요소**. 교재를 쓰면(또는 탭을 처음 열면) 적합도가 높은 요소를 **먼저 자동 배정**하고 「확정」을 기다립니다. 교재를 분석한 AI 추천(적합도·덮는 학습목표·근거, 참조 목록/미검증/목록 밖 표시), 직접 선택, 선정 대기 → 저장, 교과목 대응 후보. 능력단위요소는 ncs.go.kr 원문을 보고 'NCS 참조 목록 편집'에서 등록(이 브라우저에 저장) |
| 삽화 | 교재를 새로 쓴 직후(교재 초안 생성, 교재가 없는 블록의 교안 작성) **학습내용마다 SVG 삽화를 자동으로 그려 배치**합니다. 교재를 유지하고 교수안·슬라이드만 다시 만들 때는 그리지 않습니다(④ 산출물에서 끌 수 있음, 기준 삽화가 없으면 첫 삽화를 기준으로). 과정 공용 **아트 스타일 가이드**(팔레트 역할·hex, 선 굵기, 모서리, 채색, 글자, 그림 규칙, 기준 삽화 — 레퍼런스 이미지에서 추출 가능)에 맞춰 AI가 SVG로 그림. 스크립트·외부 링크 제거, 팔레트 밖 색·선 굵기 자동 검사 → '팔레트로 맞추기', 수정 요청, SVG/PNG 저장, 학습내용에 배치(교재.md에 포함), 교재 초안이 제안한 삽화 아이디어 |
| 문제은행 | 모든 문항에 [학습목표, 밴드] 태그. L1 객관식·단답식 / L2 서술형(모범 답안+채점 요소)·코드제출(테스트 케이스) / L3 파일제출(루브릭 충족·부분·미흡), 권장 10·5·3문항 분포표. AI 생성은 같은 목표의 기존 문항과 겹치지 않게, 학습내용의 코드 언어 기준으로 만들고 자동 검수에 걸린 문항을 한 번 더 고쳐 받음(혼합 모드는 Claude 교차 검수). 문항 검수 카드(통과 n/N·지적 문항·검사 규칙 18개), CSV |

**참고 자료**: 교재 초안·AI 수정에 PDF·PPTX(슬라이드 노트 포함)·DOCX·TXT/MD·이미지를 올려 근거로 삼을 수 있습니다. 쪽 범위를 고르고 AI에 보낼 분량을 막대로 보여 줍니다. 글자가 없는 스캔 PDF·이미지는 AI가 글자를 옮겨 적습니다(Google 또는 Claude 키 필요). 참고 자료는 저장하지 않습니다. AI 작업 중에는 받은 글자 수가 보이고 **중지**할 수 있습니다.

- AI 키가 없어도 '기본 배분' · 키워드 NCS 검색 · 템플릿 조립 · 빈 문항 작성으로 작업할 수 있습니다.
- 지침 중 LMS 운영 규칙(파일명·LMS 밖 유통 금지·출제 이력·회차 결과·유지보수 진단 매트릭스)은 운영 데이터가 필요하거나 이 도구의 내보내기 기능과 충돌해 반영하지 않았습니다. 출제 이력·오답률은 LMS에서 관리합니다.
- 능력단위요소명은 ncs.go.kr에서 PDF로만 제공되어 내장 참조 목록에 없습니다. ② 학습모듈 → NCS → '목록 보기·편집'에서 확인한 요소를 등록하면 추천기가 그 안에서 먼저 고릅니다.
- NCS 개정 후에는 `node tools/build-ncs-catalog.mjs`로 참조 목록을 다시 만듭니다.

## 출력물

- **📖 교수안** — 히어로 표지 + 사이드 목차, 표·"강사 활동/설명/학생 활동" 라벨 카드, **멘트 예시는 말풍선** 콜아웃으로 변환한 읽기용 교안 문서
- **🎬 슬라이드** — 편성안을 16:9 발표 슬라이드로 변환. 표지/목차/내용/활동/마무리 레이아웃을 **자동 판별**하고, `→`는 흐름 칩, `/·` 나열은 태그 칩, 번호는 단계 핀, 핵심 메시지는 하단 배너, 이미지/시각 제안은 이미지 슬롯으로 렌더링
- **📄 교안 MD** — 생성한 교수안·슬라이드 편성안(과정 설계는 교재까지)을 **마크다운 파일 그대로** 렌더링 또는 원문으로 보고 내려받기. 목차 링크는 문서 안에서 이동하고, 부·차시가 여럿이면 **모든 부 MD**를 한 파일로 받습니다
- **🖼 이미지 자동 생성** — 원고로 생성할 때(과정 설계는 빌드할 때) 슬라이드 '이미지/시각' 제안으로 이미지를 만들어 **참고 이미지**(교수안 말미 갤러리·슬롯에서 고르기)와 **슬라이드 이미지 칸**에 자동으로 넣습니다. 부(차시)마다 끔·2·4·8장, Google API 키(Gemini 이미지) 필요. 비교·카드·한 문장 레이아웃처럼 이미지 칸이 없는 슬라이드는 고르지 않습니다. 생성 중에는 「이미지 건너뛰고 검토 →」로 글을 먼저 볼 수 있고(만들던 이미지까지는 넣음), 과정 설계 빌드에서 12장이 넘으면 먼저 묻습니다. 연달아 두 번 실패하면 남은 이미지는 건너뜁니다. 참고 이미지 칸(24장)은 자동 이미지가 16장까지만 쓰고 나머지는 직접 올리는 자리로 남깁니다. 내려받은 MD에는 그림이 함께 들어가 다시 올려도 남습니다
- **테마 토글** — 🍄 메이플 월드 / 🌙 디벨로켓 다크
- **편집** — 서식 툴바, 선택·드래그·크기조절, 다중선택, Ctrl+C/V/X·Delete, 이미지(JPG/PNG/GIF) 삽입·붙여넣기, **레이아웃 갤러리(11종)**, 슬라이드 복제/추가/삭제, 썸네일 레일
- **내보내기** — PDF(화면 동일·슬라이드 가로 1장 1페이지) / HTML(폰트 내장) / PPTX(편집 가능)

## 입력 MD 형식 (범용)

`--- 프론트매터 ---` + 정해진 섹션/헤더 구조면 **어떤 차시 MD든** 동작합니다.

### 슬라이드 편성안
```md
---
교과목: 오리엔테이션 & 나의 목표 찾기
주제: 목표설정과 자기소개
---

## 슬라이드 편성

### 슬라이드 1 - 표지
- 슬라이드 문구:
  - (제목) 목표설정과 자기소개
  - (부제) 나를 알고, 목표를 세우고, 동료를 만나다
- 이미지/시각: 메이플 캐릭터가 출발하는 장면
- 핵심 메시지: 오늘의 한 줄 메시지
```

- 제목 태그: `(제목)` `(부제)` `(큰 문구)` `(하단)` `(한 줄)`
- 슬라이드 종류 자동 판별: 표지/목차/활동(`[활동]`)/마무리(정리·클로징)/내용
- 문구 안의 `A → B → C`(흐름), `가 / 나 / 다`(태그 칩), `1. …`(단계)는 자동 시각화

### 교수안
```md
---
교과목: …
주제: …
소요: 6시수(약 360분)
---

# 교수안 - 제목

## 학습 목표
- …

### 도입 - …
**강사 활동**: …
**설명 내용**: …
**멘트 예시**: "…"   ← 말풍선 콜아웃으로 변환
**학생 활동**: …
```

- 표(`| … |`), 리스트(중첩 지원), `**라벨**: 내용` 라벨 문단을 카드로 렌더링
- `**멘트 예시**` / `**대사**` 라벨은 💬 말풍선 콜아웃으로 변환

## AI 생성 백엔드

AI 호출은 `assets/ai-client.js` 한 곳을 거치며, 작업의 **역할**에 따라 공급자를 고릅니다(규칙: `assets/ai-config.js`).

| 역할 | Google 키만 | Claude 키만 | 두 키 모두(혼합 모드) |
|---|---|---|---|
| 구조 설계·시간 배분·NCS 판단 | Gemini | Claude | **Claude** |
| 교재·교수안 본문 작성 | Gemini | Claude | **Claude** — 어투 규칙 준수·장문 한국어 |
| 슬라이드 문구·요약 | Gemini | Claude | **Gemini Flash** — 빠르고 저렴 |
| 문항 초안 생성 | Gemini | Claude | **Gemini Flash** |
| 문항 교차 검수 | (규칙 검수만) | (규칙 검수만) | **Claude** — 생성 모델과 다른 모델이 검수 |
| 슬라이드 삽화 | Gemini 이미지 | 불가 | **Gemini 이미지** |

NCS 추천은 혼합 모드에서 두 모델이 각자 고른 뒤 합의한 항목을 '교차 검증'으로 표시합니다.

- **키 보관** — 각 키는 이 브라우저의 localStorage에만 저장되고, 요청 헤더(`x-goog-api-key` / `x-api-key`)로만 전송됩니다. 키가 없는 공급자로의 호출은 `ai-config.js`의 가드가 차단하며, 예전 Supabase 엣지 펑션은 차단된 상태입니다.
- **Gemini** — REST(`v1beta/models/{모델}:generateContent`). 생성 화면에서 2.5 Pro / Flash / Flash-Lite 선택, 이미지는 `gemini-2.5-flash-image`.
- **Claude** — 공식 SDK `@anthropic-ai/sdk@0.133.0`을 처음 쓸 때 jsDelivr에서 불러와(`dangerouslyAllowBrowser`) 스트리밍으로 호출합니다. 모델은 Opus 5.5(기본) / Sonnet 5.5 / Haiku 5.5, 역할별 effort(low/medium). Opus·Sonnet에는 정책상 거절 시 서버가 다른 모델로 자동 재시도하는 **server-side fallback**(`fallbacks: "default"`)을 켜 두었습니다.
- **호스트 폴백** — `window.claude.complete`가 있는 환경에서는 키 없이도 그쪽으로 동작합니다.
